# My IPTV Personal Xtream
Use Playlist → Xtream Codes and enter Server URL, Username and Password.
Credentials are not hard-coded into the source. They remain in the browser session by default; optional "Remember" uses localStorage.
Because this is GitHub Pages, direct Xtream API access and playback depend on the provider allowing browser/CORS access.
Never commit subscription credentials to GitHub. Use only streams you are authorized to access.
